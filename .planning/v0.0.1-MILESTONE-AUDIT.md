## Definition of Done (ROADMAP)

v0.0.1 ships a single Nx executor (`angular-typecheck`) that runs the complete
Angular compiler diagnostic set (TypeScript + template type-check + extended
NG8xxx) with no emit, decoupled from build and test -- published to npm,
cacheable, and gated by a cross-OS CI matrix. Every borrowed prior-art pattern
re-validated against Nx 23 / Angular 22 / TS 6 / Node 24.

**Verdict:** Achieved. The core value -- the complete Angular type-check for any
project type without building the app or running the tests -- is delivered as a
CommonJS Nx executor that loads ESM `@angular/compiler-cli` via `await import()`,
validated across all five project types against the installed tarball, published
live to npm (0.0.1 + 0.0.2) via tokenless OIDC with SLSA provenance.

**Verdict: everything wired. 0 integration gaps, 4/4 E2E flows complete.**

The checker read the actual files (nx.json, both workflow YAMLs, source + dist

adapter + core chain, dist build output, the e2e specs, the GATE A test, the live
GitHub rulesets) -- not the SUMMARYs.

Wiring chain (core -> adapter -> package -> CI -> release), all WIRED:
- **Core -> adapter:** `executor.ts` composes `normalizeOptions -> runTypecheck ->
  renderReport -> stdout -> evaluateResult -> {success}`, infra-error caught,
  others re-thrown. `core/` has ZERO `@nx/devkit` imports (boundary intact);
  `src/index.ts` re-exports every function the adapter consumes;
  `gatherAllDiagnostics` wired into `performCompilation`.
- **Executor-id consistency** (most-checked seam): resolves consistently in
  executors.json, schema.json, nx.json targetDefaults (BOTH the published
  `angular-typechecker:angular-typecheck` and the local-dev scoped
  `@angular-typechecker/angular-typechecker:angular-typecheck` forms, both keys
  present by design), and every e2e fixture project.json. No mismatch.
- **Package -> tarball:** package.json `main`/`types`/`executors`/`exports` all
  point at paths the build emits into dist; the tarball ships executors.json +
  schema.json + executor.js + index.{js,d.ts} + README + LICENSE (asserted by
  tarball-audit spec). devkit pinned dep, no `nx`; peers correct.
