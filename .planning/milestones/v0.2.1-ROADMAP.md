# Milestone v0.2.1: Angular CLI workspace support

**Status:** SHIPPED 2026-07-16 (`angular-typechecker@0.2.1`, npm, live)
**Phases:** 21-24
**Total Plans:** 14 (3 original + 3 gap-closure in Phase 24)

## Overview

Makes `angular-typechecker` install and run in a non-Nx Angular CLI (`angular.json`)
workspace -- `ng add angular-typechecker`, the `configuration`/`init` generators exposed
as Angular CLI schematics, and the `typecheck` executor exposed as an Angular CLI builder
-- proven end-to-end against real OSS Angular CLI workspaces. Purely additive beside the
existing Nx surface: no breaking change to the Nx executor id, the `runTypecheck`/
`CoreResult`/`CoreOptions` public API, or the existing generator/executor schemas.

## Phases

**Goal**: Prove the CommonJS-executor-loads-ESM-`@angular/compiler-cli`-via-`await import()`
engine survives `convertNxExecutor` + a real `ng run` on-stack (Angular 22), then widen
`tsConfig` to `string | string[]` so a single target can check a project's complete leaf set.
**Depends on**: v0.2.0 (shipped)
**Requirements**: ENG-01, ACB-01, ACB-02 (GATE A', GO/NO-GO), ACB-03
**Plans**: 3 plans

Plans:

- [x] 21-01: GATE A' spike (VALIDATED, GO) -- the shipped CJS->ESM `await import()` bridge survives `convertNxExecutor` + a real `ng run <project>:typecheck` against the real `bluehalo/ngx-leaflet` clone (app + library), no `ERR_REQUIRE_ESM`; minimal builder = `convertNxExecutor(typecheckExecutor)` + `builders.json` + additive `builders` field. Human GATE A' checkpoint = GO; NO-GO would never have fallen back to a hand-written architect builder.
- [x] 21-02: ENG-01 -- `tsConfig` widened to `string | string[]` at four additive seams (schema, executor schema `oneOf`, normalize-options, `CoreOptions`); `handleMultiTsConfig` unions each entry's diagnostics and finalizes once over the combined declared input set; single-string path byte-unchanged.
- [x] 21-03: In-repo CI-authoritative builder guard suite (schema-parity, thin-wrapper structural parity, Nx-surface-regression) -- zero production code, locks the builder as a thin `convertNxExecutor` re-export (never a hand-written architect builder).

**Details:**
GATE A' (ACB-02) gated the whole milestone -- a NO-GO would have re-scoped the builder
rather than fall back to a hand-written `@angular-devkit/architect` builder. Resolved GO
via spike 011 against a real cloned OSS Angular 22 workspace.

### Phase 22: Configuration schematic -- the angular.json write-fork

**Goal**: `ng generate angular-typechecker:configuration <project>` wires ONE per-project
`typecheck` architect target into `angular.json` with `tsConfig: [buildLeaf, specLeaf]`,
while the Nx `configuration` generator path stays behavior-unchanged.
**Depends on**: Phase 21
**Requirements**: ACS-01, ACS-02, ACS-04, COV-01
**Plans**: 2 plans

Plans:

- [x] 22-01: `resolveTsConfigLeaves` (Approach A: projectType-convention + existence probe; `--tsConfig` override; empty-array throw) + an early `tree.exists('angular.json')` write-fork in the shared `configuration` generator, writing `architect.<target> = { builder, tsConfig: [buildLeaf, specLeaf] }` via `updateJson`; collision-by-builder-id, idempotent; Nx else-branch byte-unchanged.
- [x] 22-02: additive `ng generate` surface -- new `collection.json` (configuration only) + `convertNxGenerator(configurationGenerator)` re-export + `package.json` `schematics` field; `generators ?? schematics` keeps the collection Nx-invisible (ACS-04 regression guard).

**Details:**
The highest design-weight phase in the milestone -- the `angular.json` write-fork chose
Option A (`tsConfig: [buildLeaf, specLeaf]` config-edit-only) over an emitted per-project
solution tsconfig, keeping the generator config-edit-only per the milestone charter.

**Depends on**: Phase 22
**Requirements**: ACS-03, NGADD-01, ACP-01
**Plans**: 3 plans

Plans:

- [x] 23-01: additive `tree.exists('angular.json')` early-return fork in the shipped `init` generator -- prints the shared `NO_CACHING_NOTICE` and returns before touching `nx.json` (ACS-03); `convertNxGenerator(initGenerator)` re-export; Nx else-branch byte-unchanged.
- [x] 23-02: classified `@angular-devkit/architect` + `rxjs` as OPTIONAL `peerDependencies` (ACP-01); `nx` stays undeclared at this point (transitive via `@nx/devkit`); `ng-add.save: devDependencies` so `ng add` installs a dev tool correctly.

**Details:**

## Milestone Summary

**Key Decisions:**

- GATE A' (ACB-02) is a hard GO/NO-GO spike gating the whole milestone -- resolved GO
  against a real cloned OSS Angular 22 workspace, never a fallback to a hand-written
  `@angular-devkit/architect` builder.
- `tsConfig: string[]` (Option A, config-edit-only) chosen over an emitted per-project
  solution tsconfig for the `angular.json` write-fork -- keeps generators config-edit-only.
- `ng-add` was rewritten mid-milestone (24-06, Option C) from a `convertNxGenerator`
  composition to a vanilla nx-free `@angular-devkit/schematics` Rule, after empirically
  discovering that Angular CLI's post-install `ng-add` probe crashes loading nx's `chalk`
  chain under yarn 4's hoist -- root-cause product fix, not a workaround.
- `nx` promoted from undeclared-transitive to a direct `^23.0.0` dependency (24-04) after
  discovering yarn does not auto-install the `@nx/devkit` peer (npm/pnpm do).
- Off-stack Angular 21 verification DROPPED 2026-07-10 (user directive) -- verification is
  on-stack Angular 22 only.

**Issues Resolved:**

- yarn `ng add` install-but-no-wire (Angular CLI post-install probe crash under yarn 4) --
  fixed at the root by making `ng-add` nx-free (24-06).
- yarn does not auto-install the `@nx/devkit` peer `nx` -- fixed by declaring `nx` as a
  direct dependency (24-04).
- pnpm-workspace root-name-collision dropping the app build leaf -- proven NOT to happen
  (full `[tsconfig.app.json, tsconfig.spec.json]` array preserved) via a committed e2e (24-05).
- e2e-tier CI wall-clock (per-project matrix split, ~41% faster) and several CI hardening
  passes were handled as post-phase quick tasks (260714-sl6, 260714-wr9, 260715-050,
  260715-q3l, 260715-rze) rather than roadmap phases -- see STATE.md Quick Tasks Completed.

**Issues Deferred:**

- Phase 25 (GitHub-backed self-hosted Nx remote cache) was proposed then removed from the
  roadmap during the milestone (workspace-wide CI cache optimization, lower priority than
  the already-shipped e2e per-project split) -- tracked as a future backlog item, not this
  milestone.
- `createNodesV2` inferred targets (WALK-FUT-01), `NgtscProgram` incremental (WALK-FUT-02),
  and wider Angular support (off-stack majors) remain out of scope.

**Technical Debt Incurred:**

- None recorded as blocking; the milestone audit (`v0.2.1-MILESTONE-AUDIT.md`) resolved all
  bookkeeping items (the stale `24-VERIFICATION.md` `human_needed` frontmatter was a cosmetic
  re-flip need only, closed by the 2026-07-15 ACV-01 real-clone re-run).
