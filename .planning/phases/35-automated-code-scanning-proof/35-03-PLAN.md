## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PR event -> `code-scanning-proof` job | Untrusted PR metadata (PR number, fork flag) crosses here; must be consumed via Actions expressions / `env`, never a `run:` shell. |
| CI job -> GitHub Code Scanning | The job holds `security-events: write` to upload the SARIF and read alerts/analyses; scope is job-level only. |
| runner -> GitHub REST | The assert reads Code Scanning via the ephemeral workflow `GITHUB_TOKEN`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-35-01 | Tampering | reused `upload-sarif` action | high | mitigate | Full 40-char SHA pin `7188fc363630916deb702c7fdcf4e481b751f97a # v4.37.1` (reuse the existing dogfood pin); add NO new marketplace action -- the assert uses ambient `gh` (D-02c). |
| T-35-02 | Tampering / Elevation | PR-metadata command injection | high | mitigate | PR number + `sarif-id` passed via `env:` values (bracket syntax for `sarif-id`), never interpolated into a `run:` shell; the fork check is an Actions expression, not a shell (mirrors the `e2e` job's `PROJECT`). |
| T-35-03 | Elevation of Privilege | over-broad token scope | high | mitigate | Job-level `security-events: write` ONLY (covers upload + read); top-level stays `contents: read`; no publish/`contents: write` scope. |
