# Quick Task 260710-0ch: Address Dependabot security alerts

## Audit

Five open alerts, all npm, all `development` scope, all in `package-lock.json`:

| # | Package | Severity | Vulnerable | Patched | Reached via |
|---|---------|----------|-----------|---------|-------------|
| 5 | js-yaml | medium | `>=4.0.0 <=4.1.1` | 4.2.0 | `@verdaccio/config` |
| 2 | qs | medium | `>=6.11.1 <=6.15.1` | 6.15.2 | `@cypress/request`, `@verdaccio/middleware`, `verdaccio-audit` |
| 1 | uuid | medium | `<11.1.1` | 11.1.1 | `verdaccio > @cypress/request` |
| 4 | @babel/core | low | `<=7.29.0` | 7.29.6 | `@angular/build` |
| 3 | esbuild | low | `>=0.27.3 <0.28.1` | 0.28.1 | `@angular/build > vite` |

## Triage

- **Consumer impact: none.** The published package ships `.js` plus peer deps and bundles nothing. Every vulnerable instance is `dev=true`.
- **Exploitability: low.** esbuild is a Windows dev-server file read (we never run it); js-yaml/qs are DoS on untrusted input (verdaccio parses trusted local config); @babel/core is a build-time file read from crafted `sourceMappingURL`; uuid's missing bounds check triggers only when a `buf` argument is passed to `v3/v5/v6`, and `@cypress/request` calls `v4()` with no buffer.
- **`npm audit fix` is not the tool.** It resolves only esbuild cleanly; for js-yaml/qs/uuid it proposes downgrading verdaccio to 5.32.2 (semver-major, a downgrade). Rejected.
- **Decision:** force patched versions with npm `overrides`, then verify the verdaccio-backed e2e still passes.

## Tasks

### Task 1 -- Add scoped `overrides` and regenerate the lockfile

- **files:** `package.json`, `package-lock.json`
- **action:** Add an `overrides` block pinning `@babel/core ^7.29.6`, `esbuild ^0.28.1`, `qs ^6.15.2`, `uuid ^11.1.1` globally, and `js-yaml ^4.2.0` scoped under `@verdaccio/config`. Run `npm install`.
- **verify:** Scan the lockfile for any instance still inside a GHSA vulnerable range; expect none. Confirm `js-yaml@3.15.0` survives (istanbul path, never vulnerable).
- **done:** Zero GHSA-flagged instances; `npm audit` reports 0 vulnerabilities.

### Task 2 -- Verify no regression

- **files:** (none -- verification only)
- **action:** Run `nx run-many -t build test lint --projects=angular-typechecker`, `nx format:check`, and `nx test angular-typechecker-install-e2e` (the verdaccio -> `@cypress/request` -> uuid gate).
- **verify:** All targets green; e2e publishes to and installs from local Verdaccio on npm, pnpm, and yarn.
- **done:** Build, 348 unit tests, lint, format:check, and 37 e2e tests all pass.

## Out of scope

- Upgrading verdaccio itself (no upstream release yet moves these transitives).
- Any change to `packages/angular-typechecker/` -- this touches the root dev tree only, so `nx release` sees no version bump (`chore` type, and attribution is by changed files).
