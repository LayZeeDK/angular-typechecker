<objective>
Land WALK-02: swap the `angular-typecheck` `targetDefaults` input from `production` to the `default`
named input in `nx.json` (so `*.spec.ts` sources hash into the coarse single-target cache key and a
spec-only edit cannot replay a stale PASS), retaining `outputs: []`, the `{projectRoot}/tsconfig*.json`
glob, and `^default`; add a cache-e2e proof that a spec-only edit busts the cache plus a manifest
assertion on the `nx.json` shape; and update the README consumer guidance to the single-target walk
recipe.

Purpose: the coarse single walk target caches on ONE key. `production` excludes `*.spec.ts`, so with
the walk now type-checking the spec leaf, a spec-only change under `production` would NOT bust the
cache -> a stale PASS. `default` (the lib+spec source union) is the correct coarse input (L-5 /
Spike 005 / WALK-02).

Output: the one-line `nx.json` input swap, a cache-e2e spec + fixture + a manifest unit assertion,
and the README walk recipe.
</objective>
