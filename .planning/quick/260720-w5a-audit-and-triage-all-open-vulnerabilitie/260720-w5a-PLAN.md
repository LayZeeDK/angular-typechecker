## Triage

- **All 4 are development-scope transitive dependencies.** None appear in the published
  `angular-typechecker` package (its `files` whitelist ships only `src`, `executors.json`,
  `README.md` -- verified in packages/angular-typechecker). Zero consumer runtime exposure.
- **No real exploit path** in this repo's usage: axios prototype-pollution needs
  attacker-controlled basic-auth subfields; the babel/esbuild file-reads are build/dev-server
  vectors that never see untrusted input inside sealed CI fixtures.
- **Decision: address (clear), do not dismiss.** The repo already carries a root `overrides`
  block pinning patched `@babel/core`/`esbuild`/`qs`/`uuid`. The established maintainer
  convention is to clear transitive dev vulns via `overrides` and keep Dependabot green
  (the repo also dogfoods CodeQL + SARIF + fallow). "Remaining" work = extend that same
  pattern to the 3 lockfiles the alerts sit in.

## Tasks
