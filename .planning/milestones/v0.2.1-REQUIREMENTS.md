# Requirements: angular-typechecker (v0.2.1 -- Angular CLI workspace support, ARCHIVED)

**Defined:** 2026-07-10
**Milestone:** v0.2.1 -- Angular CLI (`angular.json`) workspace support
**Shipped:** 2026-07-16 (`angular-typechecker@0.2.1`, npm, live)
**Core Value:** Deliver the complete Angular type-check (TypeScript + template type-check + extended NG8xxx) for any project type without building the app or running the tests -- faster, in isolation, and more completely than the build's coupled check or a bare `ngc --noEmit`.

**Charter (ADDITIVE-ONLY):** every requirement below is additive beside the shipped Nx surface. No breaking changes to the Nx executor id (`angular-typechecker:typecheck`), the `runTypecheck`/`CoreResult`/`CoreOptions` public API (widening only), or the existing generator/executor schemas. Additive-only HELD for the entire milestone -- the package shipped as `0.2.1` (patch bump under 0.x conventional commits), never triggering the `v0.3.0` breaking-change escape hatch.

Design decisions and empirical verification: `.planning/research/v0.2.1-angular-cli/SUMMARY.md` (CORRECTION & LOCKED DECISIONS).

## v0.2.1 Requirements -- Outcomes

All 16 requirements shipped as specified. Each maps to exactly one roadmap phase.

### Engine -- multi-tsConfig (ENG)

- [x] **ENG-01**: The `tsConfig` option accepts `string | string[]`. -- SHIPPED (Phase 21). Widened at four additive seams (schema, executor schema `oneOf`, normalize-options, `CoreOptions`); single-string path byte-unchanged.

### Angular CLI Builder (ACB)

- [x] **ACB-01**: `ng run <project>:typecheck` via `convertNxExecutor`. -- SHIPPED (Phase 21).
- [x] **ACB-02** (GATE A', GO/NO-GO): the CJS-executor-loads-ESM-compiler-cli engine survives `convertNxExecutor` + a real `ng run` on-stack. -- **GO** (spike 011, `bluehalo/ngx-leaflet` real clone). No fallback to a hand-written architect builder was ever needed.
- [x] **ACB-03**: `builders.json` + `package.json` `builders` field additive; `nx run` unaffected. -- SHIPPED (Phase 21).

### Angular CLI Schematics (ACS)

- [x] **ACS-01**: `ng generate angular-typechecker:configuration <project>` wires `tsConfig: [buildLeaf, specLeaf]` into `angular.json`. -- SHIPPED (Phase 22).
- [x] **ACS-02**: Nx `configuration` path stays behavior-unchanged. -- SHIPPED (Phase 22), verified byte-unchanged.
- [x] **ACS-03**: `ng generate angular-typechecker:init` seeds no caching, no stray `nx.json`. -- SHIPPED (Phase 23); LATER the standalone `init` schematic was dropped entirely (quick task 260715-mia, post-audit) as a redundant parity artifact -- the Nx `init` GENERATOR (not the schematic) remains the sole caching seeder, unaffected.
- [x] **ACS-04**: `collection.json` + `package.json` `schematics` field additive; `nx g` unaffected. -- SHIPPED (Phase 22).

### ng add (NGADD)

- [x] **NGADD-01**: `ng add angular-typechecker` auto-wires every application + library project. -- SHIPPED, in two iterations. Phase 23 shipped a `convertNxGenerator`-composed `ng-add`; a post-verification gap (yarn does not auto-install the `@nx/devkit` peer `nx`, and separately Angular CLI's post-install `ng-add` probe crashed loading nx's `chalk` chain under yarn 4's hoist) was closed by Phase 24 gap-closure plans 24-04 (nx as a direct dependency) and 24-06 (rewrote `ng-add` as a vanilla nx-free `@angular-devkit/schematics` Rule) -- first-run auto-wire now works identically on npm, yarn (flat + workspace), and pnpm.

## Out of Scope (unchanged from definition)

| Feature | Reason |
|---------|--------|
| Changing the Nx `nx add` to auto-wire all Nx projects | Would change shipped v0.2.0 install UX; deferred to `createNodesV2` inference (WALK-FUT-01). |
| Hand-written `@angular-devkit/architect` builder or `@angular-devkit/schematics` Rule for the builder | Charter mandates the thin `convertNx*` re-export; confirmed unnecessary by GATE A' = GO. |
| Emitted per-project solution tsconfig | Superseded by `tsConfig: string[]` (Option A). |
| Runtime `angular.json`/tsconfig parsing in the builder | Leaves are resolved at generate-time and written into the target. |
| `.angular/cache` target caching | Angular CLI has no task-result cache to seed. |
| Machine-readable reporters (JSON / SARIF) | Project-wide deferral, unchanged. |
| `NgtscProgram` incremental / `--watch` | Deferred engine work. |
| Standalone CLI binary; Jest support; Angular CLI Storybook special-casing | Out of charter. |
| Wider Angular support (off-stack Angular 21/20; older majors) | Stack stays Nx 23 / Angular 22 / TS 6; off-stack Ng21 verification DROPPED 2026-07-10. |
