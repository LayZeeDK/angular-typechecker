| maintainer -> public artifact     | CHANGELOG.md content becomes public GitHub Release notes; internal scopes/PII must not cross this boundary.                                                           |

| Threat ID | Category               | Component                       | Disposition | Mitigation Plan                                                                                                                                                                                                 |

| T-07-02   | Tampering (config)     | nx.json changelog.createRelease | mitigate    | Never set `createRelease:"github"` (GIT_PUSH_FALSE_WITH_CREATE_RELEASE hard-error / silent un-curated push). Existing spec assertion guards it; this plan leaves it `false`.                                    |
