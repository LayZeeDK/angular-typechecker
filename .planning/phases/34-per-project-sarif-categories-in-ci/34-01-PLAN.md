## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| untrusted PR event -> code-scanning job | A `pull_request` event carries attacker-controllable metadata (title, branch name, author, fork status) into the CI job. |
| committed workspace files -> discovery/merge scripts | The two `tools/ci/*.mjs` scripts read only repo-local, committed `project.json` files and the shipped CLI's own stdout; no external/PR-controlled input. |
| merged SARIF -> GitHub Code Scanning API | The upload crosses into GitHub's Code Scanning store using a job-scoped `security-events: write` token via a SHA-pinned action. |

## STRIDE Threat Register

The surface is the CI `code-scanning` workflow job + two `tools/ci/*.mjs` scripts (repo-local fs reads + a fixed-arg `spawnSync`, no shell interpolation) + two plugin specs. Every mitigation is "preserve the existing posture" (D-05); no `high`-severity threat is open.

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-34-01 | Tampering / EoP | code-scanning `run:` steps | high | mitigate | No PR title/branch/author interpolated into any shell; discovery/merge read fixed repo files only; merge uses `spawnSync` with a fixed arg array and NO `shell: true`; the fork check stays an Actions expression, not shell. |
| T-34-02 | Elevation of Privilege | both upload steps | high | mitigate | Fork-PR skip gate `...pull_request.head.repo.fork == false` preserved verbatim on both uploads -- the analysis still RUNS on a fork PR, only the upload skips (fork token is read-only). |
| T-34-03 | Tampering | `upload-sarif` action ref | high | mitigate | `upload-sarif` stays pinned to the existing 40-char SHA `7188fc363630916deb702c7fdcf4e481b751f97a`; NO new Action is added (defeats the tj-actions mutable-tag class). |
| T-34-04 | Information Disclosure | actions/checkout | medium | mitigate | `persist-credentials: false` preserved on checkout (no token left in `.git/config`). |
| T-34-05 | Elevation of Privilege | job `permissions` | high | mitigate | `security-events: write` granted at JOB level only; top-level stays `contents: read`; `contents: read` restated in the job for checkout. Unchanged. |
| T-34-06 | Repudiation / integrity of the gate | discovery script + drift guard | medium | mitigate | `list-typecheck-projects.mjs` `throw`s on an empty set (fail-loud), and the MULTI-02 drift guard turns any dropped/added consumer into a loud RED, so silent coverage loss cannot pass green. |
