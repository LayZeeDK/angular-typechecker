<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Actions workflow trigger -> privileged publish job | An untrusted trigger (pull_request_target) with write/publish privileges is the s1ngularity injection vector. |
| Trusted Publisher trust scope -> npm publish | Whole-repo trust (vs a specific workflow filename + environment) was the TanStack vector. |
| action reference -> executed code | A mutable tag (`@v5`) repointed to malicious code is the tj-actions vector. |
| checkout credential -> artifact/log | A persisted `.git/config` credential can leak. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-11 | Elevation of Privilege / Tampering | release workflow trigger | mitigate | Tag-push trigger only; NEVER `pull_request_target`; top-level `permissions: contents: read` (D-15). |
| T-05-12 | Spoofing / Tampering | Trusted Publisher trust scope | mitigate | Trusted Publisher pinned to the EXACT workflow filename (`release.yml`) + the required-reviewer `environment` (registered by the human at 05-05); the workflow names a manual-approval environment (D-12/D-15). |
| T-05-13 | Tampering | mutable action tags | mitigate | SHA-pin ALL actions to a 40-char commit SHA + `# vN`; Dependabot github-actions keeps them fresh (D-15/D-16). |
| T-05-14 | Information Disclosure | persisted checkout credential | mitigate | `persist-credentials: false` on checkout (D-15). |
| T-05-15 | Information Disclosure | leaked long-lived npm token | mitigate | OIDC (no standing token); `NODE_AUTH_TOKEN` left UNSET (an empty value breaks OIDC -- Pitfall 2); steady-state stores no npm secret (D-13). |
| T-05-16 | Repudiation | unverifiable build origin | mitigate | npm provenance via `NPM_CONFIG_PROVENANCE: true` (workflow) + `publishConfig.provenance: true` (manifest, 05-01); post-publish verify via `npm view --json` at 05-05 (D-04/D-16). |
| T-05-SC | Tampering | npm/pip/cargo installs | mitigate | No new package installs in this plan; the only `npm i -g npm@latest` is in the CI workflow text (not executed at plan time). No `[ASSUMED]`/`[SUS]` package introduced. |
</threat_model>
