## Tech Debt / Deferred

**One reviewable item (non-blocking):**

**Phase 22/23 -- yarn-4 `ng generate :configuration` / `:init` load path is unverified.** The two
schematics remain `convertNxGenerator`-based, so their compiled `schematic.js` does
`require('@nx/devkit')`, which pulls nx's transitive `ora -> log-symbols -> chalk` chain. Under
yarn 4's hoist this is the mechanism that threw `chalk.blue is not a function` for `ng-add` before
24-06 made it vanilla nx-free. `ng add` (the primary, documented auto-wire-all path) is nx-free and
proven on all PMs; `ng generate :configuration` is the secondary single-project command, works on
npm/pnpm, and is unit-proven -- but no e2e exercises a real `ng generate` on yarn, and the README
documents it without a yarn caveat. **Recommendation before the public release:** add an
`ng generate angular-typechecker:configuration` cell to the yarn CLI e2e to prove/disprove the crash;
if it crashes, make `configuration`/`init` vanilla nx-free (low-cost -- they already share
`src/core/angular-cli-wiring.ts`). Affected REQ-IDs: ACS-01, ACS-03.

**Out-of-scope deferrals (tracked as Future Requirements in STATE.md, NOT debt from this milestone):**
Storybook SB-08, FsTree helpers, WALK-FUT-01/02, REP-RES-02b, OBS-01, standalone CLI, JSON/SARIF
reporters -- excluded by charter.
