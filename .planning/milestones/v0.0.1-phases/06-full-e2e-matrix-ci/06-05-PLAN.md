<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PR / push event -> CI runner | untrusted PR metadata could be injected into a privileged `run:` step |
| third-party GitHub Actions -> CI runner | a mutable action tag could be repointed to malicious code (tj-actions) |
| installed act binary + fixture tarball -> CI runner | act is a pinned binary download; the e2e fixture installs only THIS repo's freshly-packed tarball |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-05-01 | Elevation / Tampering | untrusted PR title/branch interpolated into a privileged run | mitigate | `on: pull_request` (NOT `pull_request_target`); top-level `permissions: contents: read`; no job re-grants write; no PR field interpolated into any `run:` step (fixed target ids/flags only) |
| T-06-05-02 | Tampering | a mutable action tag repointed to malicious code | mitigate | every action a full 40-char SHA pin (checkout@93cb6e v5.0.1, setup-node@a0853c v5.0.0, pnpm/action-setup@008330 v6.0.9) with Dependabot github-actions lockstep with release.yml; act pinned to v0.2.89; actionlint pinned |
| T-06-05-03 | Information Disclosure | a persisted checkout credential leaked via artifact/log | mitigate | `persist-credentials: false` on every checkout |
