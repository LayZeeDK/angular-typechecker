   `logger.warn` lives on the success path (gated on `result.templateCheckAborted`).
   Structurally mutually exclusive; `executor.spec.ts` asserts the warn path does not
   call `logger.error`.

   `finalize()` via `detectTemplateCheckAborted` (NG3004 scan); consumed by the
   executor. No dangling end.
4. **Single required `ci` aggregate transitively gates BOTH** P10 `typecheck-drift`
   (inside the `test` job) AND P11 `fallow` (own job). `ci.needs:` includes both;
   `contains(needs.*.result, 'failure')` gate expression unchanged. P11's ci.yml edits
   did not regress P10's drift wiring.
5. **`.fallowrc.jsonc` references existing files** (`compiler-cli-types.drift.ts`,

6. **E2E engine pipeline intact:** `runTypecheck` -> `readConfiguration(...,
