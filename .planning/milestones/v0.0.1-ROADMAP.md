# Milestone v0.0.1: angular-typechecker

**Status:** SHIPPED 2026-06-29
**Phases:** 1-7 (with inserted Phase 5.1)
**Total Plans:** 29

## Overview

v0.0.1 ships a single Nx executor (`angular-typecheck`) that runs the complete
Angular compiler diagnostic set (TypeScript + template type-check + extended
NG8xxx) with no emit, decoupled from build and test. The journey was
engine-before-Nx and riskiest-first: a gated workspace + engine spike de-risked
the custom unconditional gatherer and the CJS-loads-ESM `import()` design against
a real Angular 22 workspace; a fully testable framework-agnostic core engine was
built before any Nx code; filtering/modes/output and the human reporter completed
the core contract; a sub-50-line Nx executor adapter plus a correctness-gated
cacheable target wrapped it; packaging/publish hardening with one e2e smoke proved
the package installs and runs end-to-end (Vertical MVP); and the slow, gating full
real-workspace e2e matrix plus cross-OS CI landed last. Every borrowed prior-art
pattern was re-validated against Nx 23 / Angular 22 / TS 6 / Node 24.

The package published live to npm (0.0.1 then 0.0.2) via tokenless OIDC Trusted
Publisher with SLSA v1 provenance, and `main` was switched to a PR-only
Release-PR workflow with a clean public changelog.

## Milestone Summary

**Decimal Phases:**

- Phase 5.1: 0.0.2 first OIDC steady-state publish verification (inserted after Phase 5 to prove the tokenless OIDC steady-state publish -- the only unproven link after the 0.0.1 token-seed).

**Key Decisions:**

- Engine-before-Nx, riskiest-first phase order: a fully testable core engine existed before any Nx code; Phase 1 was a GATED spike.
- Engine: `performCompilation` + custom unconditional all-getter gatherer (Approach A), modeling `@angular/build`, not `ngc`'s phase-fail-fast short-circuit.
- Module: CJS executor + `await import()`, compiled `.js` with `module: nodenext` (NOT `commonjs`) -- assert emitted `.js` still contains `import(`.
- Dependency model: `@nx/devkit` pinned dependency (no `nx`); `@angular/compiler-cli` + `typescript` as peers.
- Test runner: Vitest via `@nx/vitest:test` (NOT `@nx/vite:test`).
- Project-boundary filter on absolute realpath-normalized `fileName` (host `getCanonicalFileName` + `realpath`), pnpm-symlink + case-insensitive-FS safe.
- Supply-chain hardening: npm Trusted Publishers (OIDC) + SLSA provenance + hardened CI + SECURITY.md + tarball audits (publint/attw).
- Release-PR flow: `main` PR-only; cut on `release/*` branch -> PR -> tag the merge commit -> OIDC publish; clean public changelog (no GSD phase/plan scopes).

**Issues Resolved:**

- Bootstrapped Nx in-place over a pre-existing `.git` + `.planning/` without clobbering tracked files (Mechanism B).
- Re-pinned the generator's default Angular 21 deps to exact 22.0.4 to match `@angular/compiler-cli@22.0.4`.
- Self-contained the `compiler-cli-types.ts` shim (removed the fragile deep `node_modules` escape) so `attw` resolves cleanly.
- DI-06-01: `.nxignore` excludes the matrix-e2e fixtures so the `nx release` preVersionCommand build no longer fails on the deliberately-uninstalled `ng-packagr`.
- First OIDC publish 404 root cause (Trusted Publisher never saved), not a registry-url problem.

**Issues Deferred:**

- `.npmrc legacy-peer-deps=true` is a dev-repo concern (the `@nx/angular@23.0.1` peer caps Angular tooling < 22.0.0); revisit when a stable `@nx/angular` admits Angular 22. Does NOT reach consumers.
