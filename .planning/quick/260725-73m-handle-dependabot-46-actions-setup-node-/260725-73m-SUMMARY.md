codeql jobs, because act does not apply `on: push: branches:` filters. `ci.yml` behaves
identically on that plan (both `ci/` and `codeql/` appear alongside `release/`), so this is
uniform documented act behavior, not codeql-specific. Real GitHub honors `branches: [main]`.
