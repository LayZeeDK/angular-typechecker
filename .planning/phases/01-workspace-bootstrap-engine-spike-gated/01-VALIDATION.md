# Phase 1 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.
> Source: 01-RESEARCH.md "Validation Architecture". This phase is a GATED spike — the
> six go/no-go checklist items in 01-CONTEXT.md ARE the load-bearing validations.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Vitest 4.1.9 via `@nx/vitest:test` (Nx 23.0.1) |
| **Config file** | `packages/angular-typechecker/vitest.config.ts` (generated by `@nx/plugin:plugin --unitTestRunner=vitest`; created in Wave 0 if absent) |
| **Quick run command** | `npx nx test angular-typechecker` |
| **Full suite command** | `npx nx build angular-typechecker && npx nx test angular-typechecker` |
| **Estimated runtime** | ~30-90 seconds (real compiler-cli load on the integration gate spec dominates) |

Note: GATE A static asserts on the BUILT `dist/.../executor.js`, so `nx build` MUST precede the
test run for that spec. The full suite command enforces build-before-test ordering.

---

## Sampling Rate

- **After every task commit:** Run `npx nx test angular-typechecker` (Vitest; fast)
- **After every plan wave:** Run `npx nx build angular-typechecker && npx nx test angular-typechecker` (build must precede GATE A static)
- **Before `/gsd:verify-work`:** Full suite green AND all six gate items pass on one app + one lib + a recorded timing
- **Max feedback latency:** ~90 seconds
