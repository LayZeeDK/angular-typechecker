## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PR author -> ci.yml run steps | Untrusted PR metadata could be interpolated into a privileged step. This change uses fixed target ids + `${{ matrix.project }}` (from the trusted build-job output / a fixed fallback) + fixed action inputs only — no PR title/branch/author interpolation. |
| build job artifact -> e2e cells | The build job produces `dist/` + `.nx/cache` consumed by every cell. A poisoned artifact could inject build output. | GitHub Actions cache (Lever B) -> e2e cells | Cross-run Verdaccio storage cache. Fidelity-safe by construction: `resetVerdaccioPublishState` wipes the plugin + htpasswd each run and `uplinks.npmjs.maxage:60m` revalidates — the cache changes SPEED only, never correctness. |
