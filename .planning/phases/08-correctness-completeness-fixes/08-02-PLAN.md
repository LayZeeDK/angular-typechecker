<objective>
COR-02: Global / location-less TypeScript semantic diagnostics (e.g. TS2318) are
gathered via `program.getTsProgram().getGlobalDiagnostics()` and reported.

Purpose: The current 6-getter gatherer misses global TS diagnostics entirely -- the
per-file `getTsSemanticDiagnostics()` path never emits TS2318-class errors (verified: it
returns `[]` for the fixture; `getGlobalDiagnostics()` returns the TS2318 set, all
file-less). `@angular/build` calls `getGlobalDiagnostics()` explicitly. Without this, a
real global type error escapes the type-check (under-reporting).

Output: One added `all.push(...)` in `gather-diagnostics.ts`, a unit wiring proof, a new
real-compiler fixture (`noLib` + `types: []`) and a dedicated integration spec asserting
the engine now surfaces TS2318. No shim edit (`getGlobalDiagnostics` is on the public
`ts.Program` reached via `getTsProgram()`).
</objective>
