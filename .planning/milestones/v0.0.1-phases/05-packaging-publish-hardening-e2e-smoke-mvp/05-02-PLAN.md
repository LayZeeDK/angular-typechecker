<objective>
Prove the packed tarball is publish-correct by auditing the actual artifact (not the source tree). This is the second vertical-slice task: after 05-01 made the manifest + types correct, this plan builds, packs, and runs the ecosystem's own audit tools against the `.tgz` -- and the `attw --pack` problems-empty assertion is what VERIFIES the D-10/B-02 fix landed.

Purpose: A source-tree check cannot catch `files`-allowlist defects, `.d.ts` resolution escapes (D-10), or a stale-dist ship -- only an audit of the packed dist can (Pitfall 5). This gate also permanently guards against a future regression reintroducing a leak, a postinstall payload, or a broken type surface.

Output: A new dedicated, fully-serialized `angular-typechecker-install-e2e` project (cloned from the Phase-4 cache-e2e harness), a `tarball-audit.int.spec.ts` running publint + attw + positive/negative file-set + no-install-scripts gates against the packed tarball, and two new ROOT devDependencies (`publint`, `@arethetypeswrong/cli`).
