Signal 2, the engine half (the version-bumping `feat`): add a pure diagnostic-derived detector that
flags unresolved TS2307 whose module specifier contains a `?` bundler query, carry it on `CoreResult`
as an additive `bundlerQueryImports?: readonly string[]`, and prove it with the pure unit tier, the
D-05 verdict-neutrality tripwire, and a hermetic real-compiler integration fixture. This is the
fourth instance of the shipped pure-detector -> additive-optional-field triad (templateCheckAborted /
skippedReferences / notTypeCheckedDeclaredFiles) and the SIMPLEST: it reads the diagnostics array
already held in `finalize`, not the tsconfig, so there is ZERO walk threading (D-02). It is always-on
and self-gating -- no new public option (D-03).

Purpose: give consumers and agents a machine-readable, verdict-neutral signal that a run's TS2307 are
Vite/Analog bundler-query imports fixable with `"types": ["vite/client"]` -- without ever suppressing
the underlying error (charter: never a silent false pass).

Output: the pure `detect-bundler-query-imports.ts` + `CoreResult.bundlerQueryImports` + the single
`finalize` call site + full unit + integration + tripwire coverage. The executor render is 20-02; the
docs are 20-03.
