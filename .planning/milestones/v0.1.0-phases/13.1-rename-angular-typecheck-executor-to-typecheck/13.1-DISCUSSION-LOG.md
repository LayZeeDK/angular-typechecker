## Rename discipline — avoid clobbering the package name

| Option | Description | Selected |
|--------|-------------|----------|
| Anchored, verified replacements | Replace only `:angular-typecheck` / `executors/angular-typecheck` / target-key / run-command tokens; grep-verify after | ✓ |
| Bare global replace | `angular-typecheck` -> `typecheck` across the tree | |

**Selected:** Anchored, verified replacements (recommended default).
**Notes:** `angular-typecheck` is a prefix of the package name `angular-typechecker`; a bare global replace corrupts it to `typecheckr` and breaks the build. Post-rename verification: zero `:angular-typecheck` / `executors/angular-typecheck` / `"angular-typecheck"` target keys in shipped source/config/docs; `angular-typechecker` package count unchanged. IMPACT high / CONFIDENCE high; auto-locked.
